# orderbook-watchtower: og order book, swap requests and ER-24 watchtower vs pure/xln.ts

Tests: `pure/diff/orderbook-watchtower.test.ts`. Run from `pure/` with `bun test diff/orderbook-watchtower.test.ts`: 8 pass, 0 fail, about 19.8k expects.

Every test is `MATCH:` and runs against live og (`core/`, HEAD 566c850). All randomness comes from a seeded mulberry32.
