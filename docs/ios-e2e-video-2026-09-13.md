## Что именно проверено

12 выбранных сценариев реализованного клиента выполнены через интерфейс Simulator.
Это ограниченный E2E-прогон, не исчерпывающий тест всех состояний и не App Store acceptance.
Фактическое устройство: **iPhone 17 Pro, iOS 26.5**. Профиль iPhone 18 Pro недоступен.
Локальный Testnet: реальные runtime/H1/H2 и канонические финансовые переходы, тестовые средства.
SwiftUI отвечает за интерфейс, упакованный TypeScript runtime — за протокол.

## Проверки и оставшиеся границы

- Целевые тесты: **26 pass / 0 fail / 93 assertions**, 7 файлов. Это не XCUITest suite.
- Debug и Release собираются; конечная Release установлена с сохранением Keychain и остатков.
- Проверка durable export подтвердила единственность нового платежа, обе комиссии и конечные суммы.
- Общий `bun run check` не зелёный: `TEST_WORKSPACE_BUDGET_EXCEEDED`, workspace
  **77,268,221,952 > 53,687,091,200 bytes** при первом запуске этого прогона. Данные не удалялись,
  ограничение не повышалось. Успешная сборка frontend не отменяет этот результат.
- Повторный финальный `bun run check`: та же причина, **76,673,159,168 > 53,687,091,200 bytes**.
  Полное декодирование итогового видео прошло с exit 0, без ошибок; SHA-256 артефактов —
  [artifact-evidence.json](../output/ios-e2e-video-2026-09-13/artifact-evidence.json).

Не реализованы/не доказаны: backup/import и восстановление на другом устройстве, вывод,
cross-J swap, Move, сканер, APNs, offline/reconnect с незавершённой операцией, полный набор
отказов Face ID, реальное устройство и TestFlight. Apple signing identity отсутствует.
«Все функции идеальны» на основании этих 12 сценариев утверждать нельзя.
