## Реальная топология и экономический результат

H1/H2/H3 онлайн; 6 прямых соединений. Между каждой парой хабов опубликованы
двусторонние лимиты 2,000,000 тестовых USDC; collateral = 0. Это существующие
параметры локального стенда, не предложенный лимит риска для реальных средств.
Остатки и Account состояния получены через живые API и кошельки.

Путь: отправитель → H1 → H2 → H3 → получатель.

| Участок | Сумма USDC |
|---|---:|
| Отправитель → H1 | 25.000075 |
| H1 → H2 | 25.000050 |
| H2 → H3 | 25.000025 |
| H3 → Получатель | 25.000000 |

Комиссия каждого хаба: 0.000025 USDC. Всего 0.000075 USDC.
Сначала прошёл платёж из браузерного BrainVault, затем отдельный платёж из SwiftUI.
Получатель получил 50 USDC суммарно. Это две тестовые операции, коммерческий MML = 0.

Для нативного платежа сверены шесть представлений четырёх счетов; оба представления
каждого межхабового счёта имеют одинаковые Delta и высоту. Pending и mempool на этих
счетах равны нулю. Противоположные hubOutCapacity закономерно различаются по стороне;
они не сравниваются как одинаковые значения.

## Исправленная первая причина

При входящей ёмкости получателя ровно 25 USDC маршрутизатор не находил платёж
на 25 USDC. Сохранены реальные опубликованные профили в regression fixture.

PathFinder начислял отправителю комиссию самому себе и требовал комиссию
последнего хаба на его исходящем счёте. Канонический HTLC admission удерживает
комиссию посредника из входящей суммы; последний счёт блокирует ровно получение.
Поиск теперь использует существующий calculateRequiredInboundForDesiredForward,
проверяет точную блокируемую сумму каждого Account и совпадает с
quoteHtlcPaymentRoute. Изменения финансового консенсуса или Solidity не требовались.

Дополнительно поиск сохраняет разные префиксы путей до полной проверки ёмкости.
Прежняя дедупликация по текущему/предыдущему узлу отбрасывала путь через третий хаб.
Общий предел поиска 4096 извлечений сохранён. Производительность этого изменения
на большой сети не измерялась.

В SwiftUI появились реальные варианты маршрута с комиссиями; по умолчанию выбран
дешёвый путь. Выбор альтернативы получает новую котировку. При ошибке обновления
старый ticket удалён; подтвердить устаревший вариант из этого экрана нельзя.

## Следующий блокер выпуска

Восстановление существующего BrainVault на чистом устройстве: bundle 26,468,699 bytes
превышает tower 4 MiB, API также имеет собственный лимит. Нельзя подменять это
успешным повторным открытием сохранённой базы. Далее требуются отказ хаба/exit,
полный торговый цикл, независимые операторы и релизные gates, включая реализованный
потолок финансового риска. Apple signing/TestFlight остаются отдельным условием.
